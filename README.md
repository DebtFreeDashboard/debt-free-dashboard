# debt-free-dashboard

DebtFree Dashboard: a debt payoff planner that keeps your data on your device.

- Website and app: https://mydebtdashboard.com (the app is `app/dashboard.html`)
- Free calculators: https://mydebtdashboard.com/calculators/
- Android: "DebtFree: Debt Payoff Tracker" on Google Play (a wrapper around this
  website, so a merge to `main` updates both)

Working instructions for anyone changing this repo: `Project_Instructions.md`.
